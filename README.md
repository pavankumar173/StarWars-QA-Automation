# StarWars App Automation (QA Assessment)

## 📌 Overview

This project contains automation scripts for the StarWars React Native application.

## 🧪 Tech Stack

* Appium
* WebdriverIO
* JavaScript
* Mocha

## 📂 Framework Design

* Page Object Model (POM)
* Dynamic test data
* Modular structure

## 🚀 How to Run

### 1. Install dependencies

npm install

### 2. Start Appium

appium

### 3. Connect device

adb devices

### 4. Run tests

npx wdio run wdio.conf.js

## ✅ Covered Flows

* Login
* Group Creation
* Invite User

## 📸 Notes

* Uses dynamic test data
* Screenshot captured on failure
